## 📌 Overview

The **Student Information System (SIS)** is a enterprise-ready web application designed to streamline student registration, data processing, and record directory management. Built following the classic **Model-View-Controller (MVC)** architectural pattern, it ensures a modular separation of concerns between presentation templates, server-side processing, and persistent database storage.

---

## 🚀 Key Features

- 📝 **Dynamic Registration Portal:** Intuitive HTML5/JSP form for enrolling new students with real-time parameter validation.
- ⚡ **Live Directory Dashboard:** Displays registered student profiles dynamically fetched via JDBC.
- 🔍 **Client-Side Live Search:** Instant JavaScript filtering on student directories by name, roll number, or course without reloading the page.
- 🔒 **Secure Data Handling:** Uses parameterized SQL `PreparedStatement` queries to prevent SQL injection vulnerabilities.
- 🎨 **Slate & Navy Design System:** Styled using custom Bootstrap 5 for high readability across desktop and mobile displays.
